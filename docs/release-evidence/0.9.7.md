## Verification

- 342 tests passed on each of wasm, wasm-gc, JavaScript, and native.
- The Wren 0.4.0 language and core suite had 779 passing cases, 0 failures,
  and 22 upstream skips or non-test files.
- All 12 standard-output fixtures matched Wren 0.4.0. The new fixture covers
  user iterators, lazy sequence timing, nested formatting, and sort callbacks
  across Fiber suspensions.
- Local instrumented coverage reached 70.80% overall and 74.58% on core paths.
- Differential testing matched all 600 generated or corpus cases with seed
  20261116.
- Six native CLI acceptance cases and the local Chromium, SDK, performance,
  and persistent VM smoke checks passed.
