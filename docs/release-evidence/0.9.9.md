## Open compatibility difference

```wren
var worker = Fiber.new {
  System.print("before")
  Fiber.suspend()
  System.print("after")
}
System.print(worker.call())
System.print("outside")
```

Wren 0.4.0 prints `before` and stops script execution. MoonWren 0.9.9 prints
`before`, `null`, and `outside`. The difference remains when suspension
occurs inside a Fiber called by the entry module.
