## Verification

- 345 tests passed on each of wasm, wasm-gc, JavaScript, and native.
- The Wren 0.4.0 language and core suite had 779 passing cases, 0 failures,
  and 22 upstream skips or non-test files.
- All 13 standard-output fixtures matched Wren 0.4.0, including the new
  nested Fiber abort fixture.
- An embedding comparison using the Wren 0.4.0 C runtime checked the
  imported foreign-class callback after resume. The callback received the
  supplied value once, and both runtimes recorded the foreign failure at
  the callback site and the caller in the entry module.
- Local instrumented coverage reached 70.90% overall and 74.72% on core paths.
