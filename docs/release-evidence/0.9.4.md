## Immutable package audit

`tools/check-published-package.ps1 -Version 0.9.4` created an unrelated
temporary project, downloaded the package from Mooncakes, checked every target,
exercised one-shot execution and a persistent `Vm`, installed the published
native CLI, and ran it successfully. The same clean-consumer path passed in the
linked GitHub Actions run.

The published ZIP SHA-256 is
`3662b8a7fc65ee12e405969c930dd246f7142d11d0787be9ef9eda28b8ee8826`.

## Post-release validation harness corrections

The first manual differential runs exposed defects in the validation harness,
not in the immutable 0.9.4 package: the upstream Wren CLI used a C function
name that conflicts with current Linux headers, generated class and Map cases
used syntax or extensions outside official Wren 0.4.0, and the harness compared
implementation-specific diagnostic prose. Commits `9624fd9`, `57f914a`,
`353b03e`, `82e56f8`, `68a1688`, and `1d14755` corrected those independent
testing issues. The final successful run used the corrected harness while
building the candidate itself from the unchanged `v0.9.4` tag.

## Known release limitations

- The pre-1.0 installed CLI executable is named `main`.
- Optional, experimental, and intentionally excluded behavior remains governed
