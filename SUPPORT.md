# Support

Use GitHub issues for reproducible MoonWren defects and documentation problems.
The bug template requests the MoonWren version, complete `moon version --all`
output, target backend, smallest Wren source, expected behavior, actual behavior,
and a reproduction command.

Questions about behavior outside [`docs/project-boundary.md`](docs/project-boundary.md)
may be closed as out of scope rather than treated as missing functionality.
Security-sensitive reports must follow [`SECURITY.md`](SECURITY.md) and must not
publish secrets or personal data.
